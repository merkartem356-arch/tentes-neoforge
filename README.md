# TentNets (NeoForge 21.1.x, Minecraft 1.21.1)

Мод: **антидроновая сеть**, **маскировочная сеть**, **тепловизор**.

## Предметы
- **Антидроновая сеть** (20 HP): рецепт — нитки и железные самородки (4 шт.). Держит 2–3 дрона или 5–6 снарядов.
- **Маскировочная сеть** (20 HP): нитки, зелёный и коричневый красители. Скрывает игрока от тепловизора.
- **Тепловизор**: держать в руке. Картинка становится чёрно-белой, другие игроки светятся белым (до 64 блоков). Игрок в маскировочной сетке или за ней не виден.

## Как ставить сетку
- Клик по боковой грани блока — вертикальная сетка вплотную к блоку.
- Клик по нижней грани потолка — горизонтальная сетка под потолком.
- Клик по боковой грани существующей сетки — продолжить её в той же плоскости (так натягивается над пропастью).
- Сетка без опоры (цепочки до твёрдого блока) отваливается.

## Физика
Мягкая: под падающим игроком провисает и слегка подбрасывает, снизу при прыжке гасит импульс, вертикальная слегка отталкивает. Два игрока, прыгающие на одной горизонтальной сетке, рвут её. 10 стадий повреждения (текстура меняется).

## Дроны и снаряды из вашего мода
Теги `data/tentnets/tags/entity_type/drones.json` и `shells.json`: впишите id ваших сущностей, например `"mymod:drone"`.
Если в id (не из minecraft) есть слова dron/uav/quad — это дрон, shell/mortar/rocket/missile/grenade — снаряд, даже без тегов.
Дрон = 8 HP урона, снаряд = 3.6 HP. Поймавшая сущность останавливается.

## Сборка
`gradle build` (нужен Java 21 и Gradle) или через GitHub Actions (вкладка Actions, готовый jar в Artifacts).
Иконки: `src/main/resources/assets/tentnets/textures/item/*.png` (16x16) можно заменить своими.
